# BusdesNativeiOS プロジェクト概要

## プロジェクトの目的
立命館大学のバス時刻表を提供するiOSアプリケーション。リアルタイムのバス到着情報、時刻表表示、お気に入りルート機能を提供。

## テクノロジースタック
- **言語**: Swift (Swift 6並行処理対応)
- **フレームワーク**: SwiftUI (UIフレームワーク)
- **データ永続化**: SwiftData (ルート保存用)
- **アーキテクチャパターン**: MVVM + Clean Architecture移行中
- **広告**: Google AdMob統合
- **プラットフォーム**: iOS (Xcode開発環境)

## プロジェクト規模
- Swiftファイル数: 40ファイル
- 主要機能:
  - ホーム画面（リアルタイムバス情報）
  - 時刻表表示
  - お気に入りルート管理
  - 設定・メニュー
  - WebView（外部リンク表示）
